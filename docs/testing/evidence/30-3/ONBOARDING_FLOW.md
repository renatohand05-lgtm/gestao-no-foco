# Onboarding Flow — Sprint 30.3

## Etapas

1. **welcome** — Bem-vindo · “Vamos configurar sua empresa em poucos minutos.”
2. **segment** — Escolha de segmento (pesquisa + ícones + descrição)
3. **company** — Dados da empresa (todos opcionais)
4. **segment_setup** — Preview de labels, menus, módulos, KPIs, fluxos, campos
5. **templates** — Templates iniciais (sem dados reais)
6. **checklist** — Checklist de implantação com progresso %
7. **import_prep** — Excel / CSV / PDF / ERP / API (arquitetura)
8. **complete** — Parabéns + próximos passos (CTAs)

## UX

- Progress bar + steps
- Autosave (localStorage + server `meta`)
- Sair e voltar
- Desktop / tablet / mobile · light / dark
- Foco, teclado, ARIA (`progressbar`, `listbox`, `alert`)

## Tempo médio

~6 minutos
